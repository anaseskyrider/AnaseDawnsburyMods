## Libraries
The following are local libraries written by me. They are intended to be used by other modders without inter-mod hard dependencies.

### [ParryLogic](https://github.com/anaseskyrider/AnaseDawnsburyMods/tree/main/%5BLibraries%5D/ParryLogic)
Provides logic for generating and using Parry actions associated with the parry trait, without creating duplicate actions when used by multiple mods, and without directly modifying items to grant actions. See library README and `ParryLogic.cs` for more information.
